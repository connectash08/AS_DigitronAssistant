Project: Digitron Version 5

Overview:
- This is my personal AI Assistant, Digitron, created to serve as a virtual chatbot capable of answering queries and doing different tasks.
- It scrapes data from Wikipedia, Wolframalpha, PyDictionary to deliver results based on user input.
- The chatbot can also search the web using the 'webbrowser' library.

Features:
- Data retrieval from Wolframalpha, Wikipedia, and PyDictionary based on user input.
- Can open websites using the webbrowser library.
- Has a clock interface that's programmed using Tkinter
- Can play games of Rock, Paper, Scissors.

Technological Tools:
- Used python libraries and imported libraries from different websites.
- IDLE 3.11.5 version used to code.
- Tkinter employed as well.

**Note: Before running the program, please make sure you have IDLE 3.11.5 installed and can install the imports mentioned in my code using 'pip' on Terminal.**

Credit goes to Wikipedia, WolframAlpha, PyDictionary, Internet Library, and various YouTube tutorials for making all this possible.
